# الأدوار والصلاحيات

*سبعة أدوار، ومدير المكتب هو المسؤول الأول والأخير. كل الصلاحيات مفروضة في قاعدة البيانات، وكل قسم يطّلع على عمله وحده (الفصل 32).*

## الأدوار السبعة

| الدور | ما يستطيعه |
| --- | --- |
| **مدير المكتب** | كل الصلاحيات، وتعديلاته تُنفَّذ مباشرة دون طلب اعتماد. ينفرد بـ: اعتماد طلبات النماذج الحساسة، والمستخدمين وأدوارهم، وصلاحيات النماذج، والحذف، وفك الدمج، والإعدادات، والتخصيص، ومساعد Claude، وسجل التدقيق الكامل. |
| **موظف مكتب المدير** | إضافة العقود وتعديل بياناتها وأعمالها، وتحديث كل النماذج (الحساسة منها بطلب اعتماد)، والبيانات المالية والمستخلصات بصفته مختصاً بنموذج «أمر بالتعاقد»، وتحرير تحليل SWOT، واعتماد الدروس المستفادة. |
| **رئيس قسم** | قسمه وحده: نماذج اختصاص قسمه في «المهام المسندة»، وتفاصيل العقود التي يشرف عليها قسمه وبرنامجها الزمني، وتحديث إنجاز إجراءات قسمه في خطة SWOT. |
| **مكتب العقود والتوريدات والمستخلصات** | الدورة المستندية: نماذج التعاقد والمستخلصات وإقفال العقد، والبيانات المالية، ورقم العقد، وأعمال العقد ودمجها، والبت في طلبات التغيير. |
| **مكتب التخطيط والتقييم وضمان الجودة** | مكتبه بأقسامه الثلاثة، وتسجيل ملاحظات التقييم والجودة، وتحديث النماذج المسندة إليه (مثل تكليف مهندس المتابعة) من «المهام المسندة». |
| **CISO** (مسؤول الأمن السيبراني) | قسم «الأمن السيبراني» كاملاً: لوحة الأمن والوضع الأمني والأنماط غير المعتادة والهويات والصلاحيات والجلسات والأجهزة ونشاط البيانات وسجل التدقيق كاملاً والبيانات الوصفية للمراسلات والحوادث (الفصل 27)، دون الاطلاع على بيانات الأقسام. وإجراءاته: إنهاء الجلسات، والإخراج من الأجهزة، وقفل الدخول، وحظر الأجهزة، وتعليق الصلاحيات الدقيقة، وقفل المحادثات، والتجميد الطارئ للمنظومة. لا يكتب في بيانات العمل ولا يغيّر الأدوار، ولا يتخذ إجراءً على حساب المدير، وكل إجراء مسجّل. |
| **موظف (خدمة ذاتية)** | لموظفي المقر الذين لا يعملون في المنظومة: صفحة «ما صُرف لي» في قسم المخازن (ما في عهدته من أصول، وما صُرف له وما أرجعه، وتأكيد الاستلام والإرجاع) ودليل الاستخدام، ولا شيء غيرهما. لا يُمنح صلاحيات دقيقة ولا وحدة، ويُربط حسابه بسجله في سجل الموظفين (الفصل 34). |

## من يملك كل عملية

| العملية | من يملكها |
| --- | --- |
| تحديث حالة نموذج في الدورة المستندية | الجهات المسندة إليها النموذج في «صلاحيات النماذج»، والمدير دائماً. النموذج الحساس من غير المدير يصبح طلب اعتماد. |
| البيانات المالية والمستخلصات وأوامر التغيير والدفعات | من يختص بنموذج «أمر بالتعاقد» (حالياً موظفو مكتب المدير ومكتب العقود)، والمدير. المستخلص المدفوع لا يعدّله ولا يحذفه إلا المدير. |
| ضمانات العقد وتأميناته: النسبتان و«لا ينطبق» وخصم التأمينات | من يختص بنموذج «أمر بالتعاقد»، والمدير (الفصل 7). |
| اعتماد أمر التغيير أو رفضه | من يختص بنموذج «اعتماد مستخلص» (حالياً موظفو مكتب المدير)، والمدير. وإعادة المعتمد أو المرفوض إلى مسودة، وحذف المعتمد، للمدير وحده (الفصل 7). |
| تشكيل لجنة الاستلام الابتدائي أو النهائي للعقد | من يختص بنموذج تكليفها في الدورة المستندية (حالياً موظفو مكتب المدير)، والمدير (الفصل 22). |
| سجل المخاطر ومراجعاته، والتقدم الدوري، والمشاكل، والتأخيرات، والتغييرات، والدروس، وتقييم الشركات | المدير، وموظفو مكتبه، ومكتب العقود، ورئيس القسم المشرف لعقود قسمه وحدها. والسجلات العامة (دون عقد) لمكتب المدير. |
| البرنامج الزمني التعاقدي للعقد (تاريخا البداية والنهاية وحالة التشغيل) | المدير، وموظفو مكتبه، ومكتب العقود، ورئيس القسم المشرف على العقد. |
| اعتماد المقايسة وإعادة فتحها | رئيس الشؤون الفنية والمدير (الفصل 28). |
| إعداد البرنامج الزمني من المقايسة: التوليد والمراحل والمدد والتبعيات والبنود الإضافية | رئيس الشؤون الفنية، والمدير، وموظفو مكتبه، ومن مُنح «إعداد البرامج الزمنية»، على البرنامج المسودة وحده (الفصل 29). |
| اعتماد البرنامج الزمني وإحالته إلى الإشراف، وإعادة فتحه | رئيس الشؤون الفنية والمدير. |
| متابعة التنفيذ: الإنجاز والتاريخان الفعليان و«{{ST_NA}}» | رئيس القسم المشرف على العقد، والمدير، وموظفو مكتبه، ومن مُنح «متابعة تنفيذ البرامج الزمنية»، على البرنامج المعتمد وحده (الفصل 30). |
| البت في طلبات التغيير (اعتماد أو رفض) وتعديل ما بُتّ فيه | من يختص بمالية العقد، والمدير. |
| اعتماد الدروس المستفادة وتسجيل تطبيقها | المدير وموظفو مكتبه. |
| معايير مستويات الخطر وقوائمه، وإعدادات متابعة المشاريع | المدير وحده. |
| حذف خطر أو مراجعة أو أي سجل متابعة أو عقد | المدير وحده، ويبقى أثر الحذف في سجل التدقيق. |
| تحليل SWOT: العوامل والاستراتيجيات والإجراءات | المدير وموظفو مكتبه. ورئيس القسم يحدّث إنجاز الإجراءات المسندة إلى قسمه أو إلى «جميع الأقسام». |
| المقايسات: الإضافة والإصدارات والملفات | المدير، وموظفو مكتبه، ورئيس قسم الشؤون الفنية، ومن يرى الشؤون الفنية من وحدتها أو بصلاحية «المقايسات» (الفصل 32). |
| المراسلات: الوارد والصادر والداخلي | المدير، وموظفو مكتبه، ورئيس قسم الشؤون الفنية، ومن يرى الشؤون الفنية من وحدتها أو بصلاحية «المراسلات». |
| التصاميم: الإضافة والإصدارات والصور | المدير، وموظفو مكتبه، ورئيس قسم الشؤون الفنية، ومن مُنح صلاحية «التصاميم» (كرئيس الترميم لتصاميم عقوده). |
| التقارير اليومية للإشراف | المدير، وموظفو مكتبه، ورئيس القسم المشرف على العقد. والاطلاع عليها وتسجيل الملاحظة للمدير وحده. |
| حذف إصدار أو ملف أو تقرير يومي | المدير، أو من أضافه خلال 24 ساعة من إضافته. وحذف المستند كله للمدير وحده. |
| سجل المباني التاريخية وتقييمات الحالة | المدير، وموظفو مكتبه، ورئيس قسم الترميم، ومستخدمو وحدة «الترميم والمباني التاريخية» (الفصل 19). |
| الخطط، والتدقيقات، والتكليفات | المدير، وموظفو مكتبه، ودور مكتب التخطيط وضمان الجودة، ومستخدمو كل قسم من أقسامه الثلاثة (الفصل 20). |
| جولات التفتيش والحوادث والمخالفات | المدير، وموظفو مكتبه، ومستخدمو «مكتب السلامة المهنية» (الفصل 21). |
| محاضر الاستلام والملاحظات، والاختبارات وحالات عدم المطابقة | المدير، وموظفو مكتبه، ورئيس قسم المطابقة والاستلام، ومستخدمو كل وحدة (الفصل 22). |
| اعتماد المواد | المدير، وموظفو مكتبه، ورئيس قسم الشؤون الفنية، ومستخدمو «قسم الشؤون الفنية» (الفصل 17). |
| حذف سجل وحدة أو مرفقه | المدير ورئيس الوحدة، أو من أضافه خلال 24 ساعة. |
| إسناد المستخدم إلى وحدة، عضواً أو رئيساً | المدير وحده (الفصل 23). |
| التصدير والطباعة ومكتبة الوسائط | كل الأعضاء المفعّلين، لما يطّلعون عليه. وكل استخراج يُسجَّل في التدقيق (الفصل 25). |
| قوالب الطباعة العامة والقالب الافتراضي | المدير وموظفو مكتبه. والقوالب الخاصة لكل مستخدم (الفصل 25). |

| المراسلات الداخلية: المحادثات الخاصة والمجموعات | كل الأعضاء المفعّلين. والقنوات ينشئها المدير ويحدد جمهورها (الفصل 26). |
| قفل محادثة والاطلاع على البيانات الوصفية للمراسلات | المدير ومسؤول الأمن السيبراني، دون نصوص الرسائل (الفصل 27). |
| صيغ الأرقام الإشارية وضبط تسلسلها | المدير وحده. وسجل الأرقام لمكتب المدير، ولكل مستخدم أرقامه (الفصل 25). |
| الصلاحيات الدقيقة لمستخدم | يمنحها المدير ويسحبها، ويعلّقها مسؤول الأمن عند الحاجة. |
| تخصيص أسماء الأقسام والصفحات وترتيبها وإخفائها | المدير وحده (الفصل 23). |
| تهيئة المخازن: الإدارات وسجل الموظفين وربط الحسابات، والمواقع والمخازن والتصنيفات والوحدات وسياسات الإهلاك والإعدادات | المدير، ومن مُنح «مدير النظام في المخازن» (الفصل 34). |
| بطاقات الأصناف واستيرادها | المدير، و«مدير المخازن»، و«مدير النظام في المخازن» (الفصل 34). |
| إعداد مستندات المخزون وتقديمها وترحيلها بعد اعتمادها | المدير، و«مدير المخازن» لكل المخازن، و«أمين المخزن» لمخزنه وحده (الفصل 34). |
| اعتماد مستندات المخزون وإعادتها ورفضها، وإلغاء المعتمد، وعكس المرحَّل، واستثناء الاحتياطي الحرج | المدير و«مدير المخازن»، ومن أنشأ المستند أو قدّمه لا يعتمده ما دام فصل المهام مفعّلاً (الفصل 34). |
| سجل الأصول واستيراده، وتسليم العهد واستلامها، ونقل الأصول وتغيير وضعها، وطلب الاستبعاد | المدير، و«مدير المخازن»، و«مسؤول الأصول والعهد» (الفصل 34). |
| اعتماد استبعاد الأصل أو رفضه | المدير و«مدير المخازن»، ومن طلب الاستبعاد لا يعتمده ما دام فصل المهام مفعّلاً (الفصل 34). |
| تأكيد استلام ما صُرف | الموظف المرتبط حسابه بسجله، لمستنداته وحدها (الفصل 34). |

توزيع النماذج على الجهات، وتحديد أيها حساس، قابلان للتعديل من «لوحة التحكم ← الصلاحيات» دون برمجة.

**أين تُفرض الصلاحيات:** لا يكتب أي مستخدم في جداول قاعدة البيانات مباشرة. كل إضافة أو تعديل أو حذف، من إنشاء العقد إلى تغيير المستخدم اسمه، يمر بدالة في قاعدة البيانات تتحقق من صلاحية صاحبه بالجدول أعلاه، ثم تسجّله في سجل التدقيق. فلا تتجاوز الصلاحيات نسخةٌ قديمة من التطبيق ولا طلبٌ يُرسل من خارجه (الترحيل 26).

## عزل الأقسام

كل مستخدم يرى قسمه وحده، ومدير المكتب وموظفو مكتبه يرون كل الأقسام للمتابعة. ومن له قسم واحد يدخل إليه مباشرة. والنماذج المسندة إلى قسم من الدورة المستندية تظهر له في صفحة «المهام المسندة» دون بقية الدورة، وأساسيات العقود (الرقم والاسم والشركة) متاحة للربط دون ماليتها. التفاصيل في الفصل 32.

## الصلاحيات الدقيقة

يمنح المدير مستخدماً صلاحية الكتابة في **بند واحد** دون القسم كله، فوق صلاحيات دوره، فيظهر له قسم ذلك البند (الفصل 32). من «لوحة التحكم ← المستخدمون والأدوار» افتح المستخدم، ثم «الصلاحيات الدقيقة ← تعديل»، واختر:

| النطاق | ما يتيحه |
| --- | --- |
| نموذج من نماذج الدورة المستندية | تحديث حالة هذا النموذج وحده في كل العقود (والحساس منه بطلب اعتماد كالمعتاد). ونموذج «أمر بالتعاقد» يشمل البيانات المالية للعقد وأعماله، والنموذج المرتبط بمهندس يشمل تكليف المهندس |
| المقايسات أو المراسلات أو التصاميم | إضافة المستندات وإصداراتها وملفاتها في هذا النوع وحده |
| التقارير اليومية للمواقع | كتابة تقارير الإشراف لكل العقود الجارية |
| إعداد البرامج الزمنية | البنود والمراحل والمدد والتوليد من المقايسة المعتمدة لكل العقود، دون الاعتماد |
| عرض البرامج الزمنية | يُظهر قسم الشؤون الفنية بالبرامج للاطلاع (الفصل 29) |
| إضافة أنشطة البرنامج الزمني | إضافة الأنشطة وحذفها وتعديل أسمائها وبياناتها ومراحلها، دون المدد والتواريخ |
| تعديل مدد الأنشطة | المدد وحدها |
| تعديل تواريخ البداية والنهاية | الإزاحة و«لا يبدأ قبل» والعلاقات بين الأنشطة |
| اعتماد البرنامج الزمني | الاعتماد وإعادة الفتح، ومعدلات الإنتاجية |
| متابعة تنفيذ البرامج الزمنية | الإنجاز والتاريخان الفعليان و«{{ST_NA}}» على البرامج المعتمدة لكل العقود |
| نوع سجل في وحدة | مثل «حالة عدم مطابقة» وحدها دون باقي سجلات ضبط الجودة: إضافتها وتعديلها ورفع مرفقاتها، وحذف ما أضافه خلال 24 ساعة |
| تحليل SWOT | تحرير العوامل والاستراتيجيات والإجراءات |
| مدير النظام في المخازن | الإدارات وسجل الموظفين وربط حساباتهم، والمواقع والمخازن والتصنيفات والوحدات وسياسات الإهلاك وإعدادات القسم، وبطاقات الأصناف (الفصل 34) |
| مدير المخازن | بطاقات الأصناف، واعتماد المستندات وعكسها واستثناء الاحتياطي الحرج، وحركات كل المخازن، والأصول والعهد واعتماد الاستبعاد |
| أمين مخزن (لكل مخزن) | إعداد مستندات المخزن وتقديمها، وترحيلها بعد اعتمادها، والاطلاع على أرصدته |
| مسؤول الأصول والعهد | سجل الأصول، وتسليم العهد واستلامها، والنقل وتغيير الوضع، وطلب الاستبعاد، دون مستندات المخزون وأرصدته |
| مراجع المخازن | اطلاع على كل قسم المخازن وتقاريره دون تعديل |
| مدير النظام في الصيانة | الإعدادات والفنيون، وكل ما لمدير الصيانة (الفصل 35) |
| مدير الصيانة | كل البلاغات: الفرز والإسناد والرفض والإلغاء والخطط الدورية وتأكيد الإغلاق (الفصل 35) |
| فني صيانة | بلاغاته المسندة إليه وتقدمها وتنبيهاتها (الفصل 35) |
| مراجع الصيانة | اطلاع على كل قسم الصيانة دون تعديل (الفصل 35) |
| مدير النظام في المشتريات | الموردون والإعدادات، وكل ما لمسؤول المشتريات (الفصل 36) |
| مسؤول المشتريات | عروض الأسعار وإصدار أوامر الشراء وإلغاؤها واستلامها (الفصل 36) |
| مراجع المشتريات | اطلاع على كل قسم المشتريات دون تعديل (الفصل 36) |

- لا تُمنح صلاحيات دقيقة للمدير (له كل شيء) ولا لمسؤول الأمن (يطّلع ولا يكتب) ولا لحساب «موظف (خدمة ذاتية)»، والحد الأعلى 80 صلاحية للمستخدم.
- التجميد يوقفها كباقي الصلاحيات، وتتوقف إن أُوقف الحساب أو قُفل.
- كل منح وسحب في سجل التدقيق بما أُضيف وما أُزيل، وتظهر صلاحيات كل مستخدم لمسؤول الأمن في «الهويات والصلاحيات» (الفصل 27).

## الوحدات

إضافة إلى الدور، يُسند المدير المستخدم إلى وحدة من ثماني وحدات، عضواً أو رئيساً: الترميم والمباني التاريخية، وقسم التخطيط، وقسم ضمان الجودة، وقسم المتابعة، ومكتب السلامة المهنية، ووحدة الاستلام، ووحدة ضبط الجودة، وقسم الشؤون الفنية.

- **عضو الوحدة** يكتب في سجلاتها ويطّلع عليها وحدها، لا على سجلات الوحدات الأخرى ولو كانت في قسمه (الفصل 32).
- **رئيس الوحدة** يكتب ويحذف أي سجل أو مرفق في وحدته.
- الوحدة لا تغيّر الدور: موظف مكتب المدير المُسنَد إلى وحدة يبقى بكل صلاحيات دوره.
- لا تُسند وحدة إلى المدير، فهو رئيس كل الوحدات، ولا إلى CISO لأنه يطّلع ولا يكتب.
